# 任务示例 | Worked examples

下表按来源列出本技能吸纳的具体做法。每项用目标项目自己的数据验证。
Each row identifies a method retained from its source. Use representative data from the target project.

| 来源技能 / Source | 中文操作示例 | Worked example |
| --- | --- | --- |
| `awesome-design-md`, `distinctive-design-systems` | 从现有品牌和组件提取排版、间距、色彩角色；用列表与详情两个页面验明这些选择能复用。保留设计参考的出处。 | Derive type, spacing and color roles from existing brand assets and components. Apply them to both a list and a detail view. Keep the attribution for references. |
| `better-typography` | 用真实中英文长标题、金额和时间检查换行、数字对齐及截断；在目标字号和宽度下读一遍。 | Use realistic bilingual titles, amounts and dates to inspect wrapping, numeric alignment and truncation at the intended size. |
| `better-ui`, `impeccable` | 选最难操作的一屏，检查控件的默认、焦点、禁用、错误状态；修订后用同样的内容和视口比较。 | Review default, focus, disabled and error states on the hardest screen to use. Repeat with the same data and viewport after revision. |
| `design-engineering-catalogue` | 先给问题命名，例如密集数据不可读、滚动位置丢失或动效影响操作，再选对应方法；别让参考目录替代实际页面验证。 | Name the problem first, such as illegible dense data, lost scroll position or disruptive motion. Pick the relevant reference and verify on the real page. |
| `design-taste-frontend`, `frontend-design-ui-ux` | 从用户最常做的任务倒推视觉层次。用真实长标签和空、忙、失败三种状态复核主操作是否仍清楚。 | Set hierarchy from the user's most frequent task. Use real long labels and empty, busy and failure states to check whether the primary action remains clear. |
| `responsive-craft` | 不仅换宽度，也在同宽短屏和高屏上检查表单、固定栏和对话框。用键盘或滚动到达最后一个操作，标记设计允许的滚动。 | Vary height at the same width when checking forms, fixed bars and dialogs. Reach the last action by keyboard or scrolling and distinguish intended scrolling from clipping. |
| `svg-scene-animation`, `tailwindcss-animations` | 用同一元素比较静止、运动中和减少动态效果三种状态，检查实际变换与边界；动画名称存在不足以证明元素真的动了。 | Compare the same element at rest, in motion and with reduced motion. Check actual transforms and bounds; an animation name alone does not establish visible movement. |
