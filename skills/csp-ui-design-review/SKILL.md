# 界面设计与排版 | Interface design and typography

从最高频的用户任务出发，比较页面正常、空白、错误、加载、禁用和焦点状态。复用产品现有字体、间距与颜色令牌；对同一动作保持一致表达。用真实长标题、中英文、缩放和窄屏核验截断与层次。

动画记录起止状态、取消或重复触发、减少动态效果偏好。分别在真实屏幕尺寸查看整页和局部，以控件能否辨认、读取和操作作为验收条件。

按场景查找：[任务示例 / Worked examples](references/applied-methods.md)。

## English

Start with the user's most frequent task. Compare normal, empty, loading, error, disabled and focus states. Reuse the product's type, spacing and color tokens. Test real long labels, both languages, zoom and narrow screens before adjusting hierarchy.

Check motion at its start and end, when interrupted or triggered twice, and with reduced motion. Inspect both the whole page and a local crop at realistic sizes. Verify that the control can be recognized, read and used.
