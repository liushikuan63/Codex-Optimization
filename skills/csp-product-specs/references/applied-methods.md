# 任务示例 | Worked examples

下表按来源列出本技能吸纳的具体做法。每项用目标项目自己的数据验证。
Each row identifies a method retained from its source. Use representative data from the target project.

| 来源技能 / Source | 中文操作示例 | Worked example |
| --- | --- | --- |
| `architecture-designer` | 为关键决定列出约束、两种可行方案、采用理由和会推翻该决定的条件；给迁移和回退留入口。 | For a consequential design decision, record constraints, two feasible options, the reason for the choice and the condition that would reverse it. Include migration and rollback. |
| `deliver-prd` | 把“更好用”改写成谁在什么条件下完成哪项操作；标出失败后的恢复动作与可观察结果，留下本期不做的事项。 | Turn a vague goal into an actor, starting condition, action and observable result. Include failure recovery and the scope left for later. |
| `write-repowiki` | 按真实入口、构建命令和一次典型调用组织 Wiki；从干净检出核对命令与路径，标出配置来源和仍需实测的结论。 | Organize the wiki around real entry points, build commands and one representative call. Check paths and commands from a clean checkout, and identify configuration sources and unverified claims. |
