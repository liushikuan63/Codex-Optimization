# 经验采纳与回退 | Review and roll back learned practices

先确认允许记录的范围和暂停状态。明确偏好、项目事实、待验证推测分别处理；查旧证据和反例，同一故障重试只算一次。保留触发条件、证据、适用范围与例外。

优先更新已有条目。保存原文，在一个适用例和一个不适用例上验证；记录版本与回退范围。用户后来改了同一文件，只撤回自己的改动。这个流程不授予记忆、费用、后台监听或外部写入权限。

按场景查找：[任务示例 / Worked examples](references/applied-methods.md)。

## English

Check the authorized scope and pause state. Separate explicit preferences, project facts and guesses. Look for contrary observations and count retries of one incident once. Retain the trigger, evidence, scope and exceptions.

Prefer an existing entry. Snapshot it and check a matching and a nonmatching task. Record the version and rollback boundary, preserving later user edits. This procedure grants no memory, spending, monitoring or external-write permissions.
