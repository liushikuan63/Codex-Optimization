# 跨宿主能力包吸纳

1. 固定检视版本、安装入口、来源/许可并盘点目录之外的规则、命令、工具、hook、插件和包。目录元数据用于粗筛，候选看正文、脚本、真实配置边界；记录覆盖层级。
2. 对每个条目或可核对的组记录去向：吸纳及本地入口、已有及覆盖证据、按具体场景补证、来源/宿主/授权不匹配不引入。原路径、环境、旧放行历史和命令字符串不等于本机机制。保留可复用的不变量，再选择现有技能、独立技能或小工具。
3. 改既有技能先备份并比对现状，新文件确认无重名；只安装明确列入的文件。用正反例核对路由语义与脚本行为，运行引用检查。存在受支持的技能列表查询时，从实际目标工作目录读回名称、启用状态和来源路径，确认无重复覆盖；把发现、当前会话载入和自动触发分别报告。
4. 附安装清单、内容哈希和局部回退条件。区分条目层盘点和逐文件审查；不能用已安装条数替代验证或把宿主专属自动化说成 Codex 已启用。
