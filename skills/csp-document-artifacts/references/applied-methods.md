Each row identifies a method retained from its source. Use representative data from the target project.

| 来源技能 / Source | 中文操作示例 | Worked example |
| --- | --- | --- |
| `encrypted-office-visual-inspection` | 在已有授权的文档查看器内检查可见页、行列标题和分页，记录观察范围。只看到屏幕时，不宣称已读取隐藏表格、公式或加密内容。 | Inspect visible pages, row and column headings, and pagination in an authorized viewer. State the range observed; screen inspection cannot establish hidden cells, formulas or encrypted contents. |
