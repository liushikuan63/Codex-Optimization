# 文档、表格与图表验收 | Documents, sheets and charts

1. 确认交付格式、页尺寸、数据来源、单位与读者。保留原件；选择已有的格式专用工具，只有合法可读的资料才进入处理流程。
2. 文档既要抽取正文、表格和链接，也要渲染实际文件，检查分页、字体、溢出与裁切。表格应重算公式并比较边界值、日期和空值；不能把缓存值当重算。
3. 对图表核对轴单位、基线、刻度、分母、缺失值和图例。导出后逐页或逐图复核，保留来源与结果；打不开的加密文件说明限制。

按场景查找：[任务示例 / Worked examples](references/applied-methods.md)。

## English

1. Establish the deliverable format, page size, data origin, units and audience. Preserve the original and use the available format-specific tools on authorized material.
2. Extract text, tables and links, then render the delivered document to catch clipping, font and page-break problems. Recalculate workbooks and check dates, blanks and boundary values independently of cached results.
3. Check chart axes, denominators, missing data and legends. Review the exported pages or figures. State when source protection prevents inspection.
