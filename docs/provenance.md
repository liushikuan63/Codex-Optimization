# 来源与适配

[English](provenance.en.md) · [返回首页](../README.md)

首版吸纳以 [Qoder-Optimization v0.2.2](https://github.com/liushikuan63/Qoder-Optimization/tree/fe929cf1de22d4312b9526536568161d2a674439) 为固定输入。上游 MIT 版权声明见根目录许可证。各技能的参考文档也标注对应来源；本包用 Codex 项目技能入口重述可复用方法，裁切及安装工具按包需求独立编写。

| 来源 | 本包去向 |
| --- | --- |
| verify-ui-in-browser、spa-loading-hang-triage | 浏览器验收：真实入口、不同宽高、响应类型和加载生命周期 |
| image-detail-inspect | 原图坐标、裁切与近邻放大 |
| counterexample-driven-plan-review、vibecoding-doc | 方案评审和反例证据 |
| verify-before-claim、production-readiness-audit | 需求和证据对照、上线评审 |
| intermittent-test-red-triage、structured-edit-safety、safe-text-editing、concurrent-edit-attribution-check | Windows 项目验证、定位间歇失败、编辑预检 |
| vibecoding-batch-append | 按项目编写契约追加批次 |
| skill-authoring-closure 与能力目录 | 来源、去向、引用和发现验收 |
| MCP 接入和项目规则 | 按需连接公开文档服务，提供可合并的项目约定模板 |

宿主 hook、权限流、自动发布、磁盘迁移、个人记忆和代理账号需要独立的能力与授权，未纳入。专题库、设计素材和已有等价技能按需选用；首版不整包转发上游库或第三方素材。
