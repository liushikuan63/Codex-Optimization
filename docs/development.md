# 开发和验证

- 每个目录对应一个技能；名称要和 `SKILL.md` 名称字段匹配。描述写清“何时使用”和容易误触发的情形，详细流程放到 `references/`。
- 新增可执行脚本应给出入口、依赖和可区分的正反例。需要写盘时列明目标、保留条件和退出行为。功能默认由用户或当前任务按需调用。
- 运行 `python -m unittest discover -s tests -v`。安装生命周期测试使用临时项目和真实 CLI，核对预检、冲突、改动保护和卸载；引用测试运行随包的只读审计器。真实宿主发现和自动触发需分别验证。
- 发布前查看 Git 差异和全部待发布路径，排除凭据、用户环境、会话、私有路径、未授权第三方素材和机器相关产物。版本从 `VERSION` 读取。
